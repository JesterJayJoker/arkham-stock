Privacy

Arkham Stock does not require an account.

Your collection

Owned and wanted state is stored in your browser using localStorage. Normal collection use does not send your ownership list to the Arkham Stock backend. Export creates a JSON file in your browser; import reads the file in your browser.

Server requests

The backend receives ordinary web-request metadata needed to serve the site, reuse shared retailer results, and enforce rate limits. Arkham Stock does not intentionally collect names, email addresses, passwords, or payment information.

Retailer checks

Retailer availability checks are performed by the shared Arkham Stock backend rather than separately by each visitor's browser.
