# eBay Collector Search Pilot (v0.17)

This is an opt-in **search-link pilot**, not an automated verified listing integration.

- Every retail product has a direct eBay Buy It Now search link in its product sources and stock checker, with Chapter One as the primary use case.
- Links open active eBay search results in a new tab; no eBay prices, availability, conditions, or seller claims are ingested into Arkham Stock.
- Users must confirm exact product, edition, completeness, condition, shipping, and seller.
- For accurate automated offers, approved eBay Browse API production access and secure server-side credentials are required.
- Search-link relevance can be evaluated on the five audit products before applying for API access.
