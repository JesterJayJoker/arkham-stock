# Privacy

Arkham Stock does not require an account.

Collection ownership and wanted-state are stored in the visitor's own browser using localStorage. They are not sent to the Arkham Stock backend during normal use. Exporting a collection creates a local JSON file for the visitor; importing reads that file in the browser.

The backend receives ordinary web request metadata needed to serve the site and enforce rate limits. Arkham Stock does not intentionally collect names, email addresses, passwords, or payment information.

Retailer checks are made by the shared Arkham Stock backend, not separately by each visitor's browser.
